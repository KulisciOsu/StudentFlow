
# KAN-80 – Wireframe úvodního dashboardu

## Účel
Úvodní dashboard poskytuje přihlášenému uživateli
přehled jeho projektů, úkolů a blížících se termínů.

Rozložení je společné pro studenty i vyučující.
Data se zobrazují podle přihlášeného uživatele
a jeho oprávnění.

## Responzivní varianty
- Desktop: dashboard-wireframe.svg
- Tablet: dashboard-tablet.svg
- Mobil: dashboard-mobile.svg

## Obsah dashboardu
1. Uvítání přihlášeného uživatele
2. Počet dostupných projektů
3. Počet aktivních úkolů uživatele
4. Počet blížících se termínů
5. Seznam projektů uživatele
6. Seznam nejbližších termínů

## Navigace
- Statistika projektů → seznam projektů
- Statistika úkolů → seznam mých úkolů
- Statistika termínů → sekce nejbližších termínů
- Kliknutí na projekt → detail projektu
- Kliknutí na úkol → detail úkolu

## Prázdný stav
Pokud uživatel nemá žádné projekty,
zobrazí se informační zpráva.

Uživatel s příslušným oprávněním může
přejít na založení projektu.

## Poznámky
- Wireframy obsahují pouze ukázková data.
- Dashboard je určen především pro čtení dat.
- Skutečná data bude poskytovat backend API.
- Finální barvy a vizuální styl nejsou součástí wireframu.
